# Pour chaque [tableau de mise en forme](https://accessibilite.numerique.gouv.fr/methode/glossaire/#tableau-de-mise-en-forme), le contenu linéarisé reste-t-il compréhensible?
<CriteriaA/>
<IconedLink>[Lien RGAA](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#5.3)</IconedLink>

## Que doit-on vérifier ?

<BookmarkletTags names={["05 - Tableaux"]} />

- Sur l’élément `<table>`, présence d’un `role="presentation"` (ou `role="none"`) qui supprime la sémantique de tableau.
- Le contenu reste compréhensible si le tableau est linéarisé

<details>
    <summary>
        ## Exemples
    </summary>

    <Example imgImport={CEbay} comply>
        Dans l’en-tête de la page (ebay.fr)[https://www.ebay.fr/],
        le logo et le formulaire de recherche sont intégrés dans un tableau de présentation.

        Il possède un `role="presentation"`, n’a aucun attribut ni balise de tableau de données et
        le contenu linéarisé est compréhensible.
    </Example>
</details>
