# Chaque [tableau de données complexe](https://accessibilite.numerique.gouv.fr/methode/glossaire/#tableau-de-donnees-complexe) a-t-il un [résumé](https://accessibilite.numerique.gouv.fr/methode/glossaire/#resume-de-tableau) ?
<CriteriaA/>
<IconedLink>[Lien RGAA](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#5.1)</IconedLink>

## Que cherche-t-on ?

<BookmarkletTags names={["05 - Tableaux"]} />

**Complexe si :** plus d’une ligne ou colonne d’en-tête pour une cellule de données, lorsque la portée d’un en-tête
n’est pas valable pour l’ensemble de la colonne ou ligne, fusion de cellules, etc.

Présence d’un résumé pour **expliquer l’organisation du tableau** avec l’élément `<caption>`.

Dans le cas d’un tableau ARIA, le résumé peut être intégré avec `aria-describedby`.

:::note

Les tableaux complexes sont problématiques pour les utilisateurs aveugles mais également pour certains utilisateurs
voyants qui ont un **trouble cognitif** (par exemple, la dyspraxie). Pour cette raison, il est toujours préférable de
laisser le résumé visible pour tous les utilisateurs.

:::

<details>
    <summary>
        ## Exemples
    </summary>

    <Example imgImport={NCInsee}>
        Les tableaux complexes du site [insee.fr](https://www.insee.fr/fr/statistiques/3972093#tableau-figure2)
        ne possèdent pas de résumé.
    </Example>

    Proposition de correction

    ```html
<caption>
        Figure 2 — Répartition des déchets non dangereux non minéraux hors boues de l’industrie
        manufacturière par type en 2016
        <span>
            Les industries agroalimentaires (IAA) et les industries manufacturières (hors IAA) sont
            présentées sur 2 colonnes,avec, pour chacune d’elles la quantité en milliers de tonnes le
            pourcentage. Une troisième colonne présente letotal des deux industries, en milliers de
            tonnes et enpourcentage.
        </span>
</caption>
    ```
</details>


## ARIA

- Tableau : `role="table"`
- Titre : `aria-label="Nom du tableau"` ou `aria-labelledby="@id_titre"`
- Entêtes : `role="rowheader"` / `role="columnheader"`
- Cellules : `role="cell"`

```html
<p id="titre">
    Parc et fréquentation des autres hébergements
    collectifs touristiques en 2018
</p>

<div role="table" aria-labelledby="titre">
  <div role="row">
    <div role="columnheader">Type d’hébergement professionnel</div>
    <div role="columnheader">Nombre d’établissements</div>
    [...]
  </div>
  <div role="row">
    <div role="cell">Résidences de tourisme</div>
    <div role="cell">2 426</div>
     [...]
  </div>
</div>
```

## Notes techniques (RGAA)

La spécification HTML propose plusieurs [méthodes pour lier un résumé à un tableau](https://accessibilite.numerique.gouv.fr/methode/glossaire/#table-descriptions-techniques)
(tableau lié à un passage de texte avec l’attribut `aria-describedby`, tableau groupé dans un élément `figure` avec
un résumé présent dans un élément `figcaption` ou un élément `p`, résumé présent dans un élément `details` contenu
dans l’élément `caption`). Ces méthodes n’ont pas un support suffisant pour être utilisées actuellement.
