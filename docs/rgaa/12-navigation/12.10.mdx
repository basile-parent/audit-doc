# Dans chaque page web, les [raccourcis clavier](https://accessibilite.numerique.gouv.fr/methode/glossaire/#raccourci-clavier) n’utilisant qu’une seule touche (lettre minuscule ou majuscule, ponctuation, chiffre ou symbole) sont-ils contrôlables par l’utilisateur ?

<CriteriaA/>
<IconedLink>[Lien RGAA](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#12.10)</IconedLink>
<BookmarkletTags names={["12.10 Raccourcis clavier"]} />

## Que vérifie-t-on ?

Si des raccourcis clavier constitués uniquement de caractères imprimables (alphabet, chiffres,
et autres caractères * / — etc.) déclenchent des fonctionnalités dans la page :
- il existe un mécanisme pour désactiver ou configurer le raccourci clavier avec une des
touches de modifications (`Ctrl`, `Shift`, etc.) ;
- soit le raccourci clavier n’est effectif que lorsque le focus est dans un composant particulier
(et n’est pas fonctionnel en dehors de ce composant).
