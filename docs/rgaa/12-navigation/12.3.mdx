# La [page « plan du site »](https://accessibilite.numerique.gouv.fr/methode/glossaire/#page-plan-du-site) est-elle pertinente ?

<CriteriaAA/>
<IconedLink>[Lien RGAA](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#12.3)</IconedLink>

## Que vérifie-t-on ?
- Le plan du site doit être représentatif de l’architecture générale du site (on doit pouvoir atteindre,
directement ou indirectement, l’ensemble des pages du site).
- Tous les liens doivent être **fonctionnels**.
- Les intitulés des liens doivent être pertinents

**Ressources :**
- [W3C Link Checker](https://validator.w3.org/checklink)
- [Extension Firefox permettant de contrôler les liens d’une page](https://addons.mozilla.org/fr/firefox/addon/find-broken-links/)
