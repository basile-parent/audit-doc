# Dans chaque page web, chaque [lien](https://accessibilite.numerique.gouv.fr/methode/glossaire/#lien) a-t-il un [intitulé](https://accessibilite.numerique.gouv.fr/methode/glossaire/#intitule-ou-nom-accessible-de-lien) ?

<CriteriaA/>
<IconedLink>[Lien RGAA](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#6.2)</IconedLink>
<BookmarkletTags names={["06 - Liens", "Compléments/List links"]} />

## Que vérifie-t-on ?

Tous les liens doivent avoir un nom accessible.

Lorsque le lien est constitué uniquement d’une image, attention à la présence d’une alternative
(ou autre moyen de nommage) pour créer l’intitulé du lien.

## Notes techniques

Une ancre n’est pas un lien même si pendant longtemps l’élément `<a>` a servi de support à cette technique.
Elle n’est donc pas concernée par le présent critère.
