# 3.1 Dans chaque page web, l’[information](https://accessibilite.numerique.gouv.fr/methode/glossaire/#information-donnee-par-la-couleur) ne doit pas être donnée uniquement par la couleur. Cette règle est-elle respectée ?
<CriteriaA />
<IconedLink>[Lien RGAA](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#3.1)</IconedLink>

## Cas les plus courants
- page active
- onglet sélectionné
- slide active dans un carrousel

## Alternatives courantes
- `title` sur les liens ou boutons `title="accueil - page active"`
- propriétés ARIA (`aria-current`, `aria-pressed`, `aria-selected`)
- texte positionné hors écran (`class="sr-only"`)

:::note

Une alternative pertinente est une **alternative perceptible pour tout le monde**.

Attention à l’utilisation de textes cachés en CSS par exemple qui ne seront pas vus par les personnes
déficientes visuelles qui n’utilisent pas de lecteur d’écran. Il sera souvent nécessaire de doubler
l’information par la couleur par un changement de forme (mise en gras, ajout d’une icône).

:::

## Comment le tester ?

<BookmarkletTags names={["03.1 10.9 Informations données par la couleur ou la forme"]} />

**Le bookmarklet ne fait pas grand-chose** à part afficher les items qui ont des classes CSS typiques de l'info
par la couleur ("active" par exemple).

- Rechercher les informations véhiculées par la couleur (couleur de texte, couleur de fond, graphiques, etc.)
- Vérifier que l'info est perceptible par les aveugles et les déficients visuels (attribut `title`, icône, etc.).

### Qui est concerné ?

Ce critère vise essentiellement les personnes aveugles et les personnes daltoniennes qui ne perçoivent pas
les couleurs différentes. Il n'est pas interdit d'avoir des informations par la couleur mais elles doivent être
associées à des descriptions de ce que la couleur signifie.

<details>
    <summary>
        ## Exemples
    </summary>

    <Example imgImport={CLuxImg} comply>
        Sur le site [accessibilite.public.lu](https://accessibilite.public.lu/fr/rgaa4.1/index.html), la page active
        est mise en évidence par la couleur (et une inversion de contraste) et l’ajout d’une propriété `aria-current`.

        ```html
        <a aria-current="page" href="/fr/rgaa4.1/index.html">Introduction </a>
        ```
        _Autre implémentation conforme :_

        ```html
        <a title="Introduction - page active" href="/fr/rgaa4.1/index.html">Introduction </a>
        ```
    </Example>

    <Example imgImport={NCOptionsImg}>
        Sur cette page, les services non compris dans une formule sont grisés (couleur) et barrés (forme) et précédés d’une icône (forme), mais cette information n’est pas disponible pour une personne aveugle.

        _Extrait du texte disponible dans le code source :_

        ```
        ✖ Incendie / vol / explosion
        ```

        _Correction possible :_

        ```html
        ✖ Incendie / vol / explosion
        <span class="sr-only">non compris dans cette offre</span>
        ```
    </Example>

    <Example imgImport={NCStatusImg}>
        Sur le site [ooparc.com](https://www.ooparc.com/fr/177-Parc_Disneyland/Infos/Frequentation/), l’affluence
        des parcs est indiquée par une mise en couleur des jours dans les calendriers.

        Un texte non visible est disponible dans le code source, mais il est caché en CSS par `visibility:hidden`,
        ce qui le rend inaccessible aux lecteurs et loupes d’écran. De plus, pour les utilisateurs malvoyants,
        la distinction entre les différentes couleurs reste problématique, voire impossible.

        _Extrait du texte disponible dans le code source :_

        ```html
        <td class="period-3">
            1
            <span>
                <b>Samedi 1 octobre 2022</b><br/>
                <i>Forte affluence</i>
            </span>
        </td>
        ```

        _CSS utilisée pour masquer le texte :_

        ```css
        #park-attendance tbody td span { visibility: hidden; ... }
        ```

        _Correction possible : ajouter une forme en plus de la couleur (par exemple une icône ou un motif
        associé à chacune des couleurs). Supprimer la propriété CSS `visibility:hidden` et positionner le
        texte hors écran (méthode `sr-only`)_
    </Example>

    <Example imgImport={NCCaptchaImg}>
        Le système de captcha MailInBlack propose aux utilisateurs une validation basée sur la perception d’une couleur.
    </Example>
</details>

## Résumé des tests

- Rechercher dans toute la page :
  - Des mots ayant une couleur porteuse de sens <IconedLink>[test 3.1.1](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#3.1.1)</IconedLink>
  - Des textes ayant une couleur porteuse de sens <IconedLink>[test 3.1.2](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#3.1.2)</IconedLink>
  - Des images véhiculant une information par la couleur <IconedLink>[test 3.1.3](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#3.1.3)</IconedLink>
  - Des propriétés CSS véhiculant une information par la couleur <IconedLink>[test 3.1.4](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#3.1.4)</IconedLink>
  - Des médias temporels véhiculant une information par la couleur <IconedLink>[test 3.1.5](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#3.1.5)</IconedLink>
  - Des médias non-temporels véhiculant une information par la couleur <IconedLink>[test 3.1.6](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#3.1.6)</IconedLink>
- Vérifier qu’il existe un autre moyen de récupérer cette information (présence d’un attribut `title`,
d’une icône ou d’un effet graphique de forme ou de position, un effet typographique, etc.).
_Voir [Alternatives courantes](#alternatives-courantes)_

### Penser à vérifier
- Le contraste des textes au survol d'un composant (exemple : un lien au survol)
