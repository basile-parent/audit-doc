# Dans chaque [formulaire](https://accessibilite.numerique.gouv.fr/methode/glossaire/#formulaire), les [champs de même nature](https://accessibilite.numerique.gouv.fr/methode/glossaire/#champs-de-meme-nature) sont-ils regroupés, si nécessaire ?

<CriteriaA/>
<IconedLink>[Lien RGAA](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#11.5)</IconedLink>

## Comment regrouper ?

- Réunir les éléments communs dans un `<fieldset>` et titrer avec `<legend>` ([critère 11.6](./11.6))
- ou dans un élément (`div`) avec le `role="group"` et titrer avec `aria-label` ou `aria-labelledby` ([critère 11.6](./11.6))

```html
<fieldset>
    <legend>Adresse de facturation</legend>
    [champs ...]
</fieldset>
<div role="group" aria-labelledby="toto">
    <p id="toto">Adresse de livraison</p>
    [champs ...]
</div>
```

## Aide à la détection
<BookmarkletTags names={["11.5 Regroupements"]} />

- Repérer les ensembles de champs qui devraient être regroupés et vérifier :
    - qu’ils sont entourés (présence d’un élément de regroupement `<fieldset>` ou `role="group"`)
    - qu’ils possèdent une légende pertinente.
