# 2.1 Chaque [cadre](https://accessibilite.numerique.gouv.fr/methode/glossaire/#cadre) a-t-il un [titre de cadre](https://accessibilite.numerique.gouv.fr/methode/glossaire/#titre-de-cadre) ?
<CriteriaA />
<IconedLink>[Lien RGAA](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#2.1)</IconedLink>

## Comment le tester ?

<BookmarkletTags names={["02 Cadres"]} />

- Lancer le BM `02 Cadres` qui liste toutes les `<(i)frame>`.
- Vérifier qu'elles ont toutes un `title`.

```html
<iframe title="Publicité"></iframe>
```

:::note

Le contenu des cadres est dérogé car il n'est pas sous la responsabilité de l'éditeur du site.
Cependant il doit respecter le (principe de non-interférence)[https://access42.net/principe-non-interference-accessibilite-numerique/].

De plus, il faut fournir, lors que c'est possible une alternative au contenu exempté (voir les exemples)

:::

## Résumé des tests

Pour cadre (balise `<iframe>` ou `<frame>`), vérifier que l'attribut `title` est présent.
