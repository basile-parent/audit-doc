# Dans chaque page web, le texte reste-t-il lisible lorsque la [taille des caractères](https://accessibilite.numerique.gouv.fr/methode/glossaire/#taille-des-caracteres) est augmentée jusqu’à 200 %, au moins (hors cas particuliers) ?

<CriteriaAA/>
<IconedLink>[Lien RGAA](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#10.4)</IconedLink>

## Que vérifie-t-on ?

Le texte doit pouvoir être agrandi à 200 %, sans provoquer de perte d’information.

- Utilisation du zoom graphique du navigateur (`Ctrl +` 6 fois) ;
- Ou zoom texte : dans Firefox aller dans Affichage et choisir Zoom texte seul, puis agrandir à 200 % (`Ctrl +` 6 fois) ;
- Ou utilisation d’un dispositif d’agrandissement des caractères (boutons de type A+/A-).

Ressource : [article de blog de Marie Guillaumet](https://marieguillaumet.com/refonte-mon-portfolio-du-responsive-en-em-premiere-partie/)

## Cas particuliers

Font exception à ce critère, les contenus pour lesquels l’utilisateur n’a pas de possibilité de personnalisation :

*   Les sous-titres incrustés dans une vidéo ;
*   Les textes en image ;
*   Le texte au sein d’une balise `<canvas>`.
