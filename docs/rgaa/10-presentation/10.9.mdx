# Dans chaque page web, l’information ne doit pas être donnée uniquement [par la forme, taille ou position](https://accessibilite.numerique.gouv.fr/methode/glossaire/#indication-donnee-par-la-forme-la-taille-ou-la-position). Cette règle est-elle respectée ?

<CriteriaA/>
<IconedLink>[Lien RGAA](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#10.9)</IconedLink>

## Que vérifie-t-on ?

Il existe une alternative dans la page ou sur l’élément lui-même (par exemple avec un attribut `title`).

**Exemples :** mise en gras pour véhiculer un état (importance, hiérarchie, etc.), un symbole pour informer
d’un statut (présent, disponible, absent…), une instruction ("dans la colonne de droite").

<details>
    <summary>
        ## Exemples
    </summary>

    <Example imgImport={NCMalt}>
        Sur le site [malt.fr](https://www.malt.fr/s?q=d%C3%A9veloppeur+frontend&f-fam=tech&f-cat=frontend_developer&p=1),
        dans les pages de résultats, le potentiomètre de choix du tarif/jour est associé à un histogramme qui permet
        de déterminer les disponibilités pour chaque plage de prix.

        C’est la hauteur (la forme) du bâton qui détermine l’estimation des disponibilités. Cette information
        n’est pas disponible sous forme textuelle.

        Une personne aveugle n’a pas accès ces informations.
    </Example>

    <Example imgImport={NCAppart}>
        Sur le site [appartcity.com](https://www.appartcity.com/fr/destinations/rhone-alpes/lyon/lyon-gerland.html?search%5BstartDate%5D=24/01/2025&search%5BendDate%5D=26/01/2025&search%5BnbAdult%5D=2&search%5BnbChild%5D=0&search%5Bcode%5D=),
        les services payants sont indiqués par un symbole bleu.

        Ce symbole est positionné dans un `::after` sans être repris textuellement.
    </Example>
</details>
