# Dans chaque page web, les déclarations CSS de couleurs de fond d’élément et de police sont-elles correctement utilisées ?

<CriteriaAA/>
<IconedLink>[Lien RGAA](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#10.5)</IconedLink>

## Résumé des tests
- Si une couleur de police est déclarée, alors une couleur de fond est déclarée ou héritée d’un parent.
- Inversement, si une couleur de fond est déclarée, alors une couleur de police est déclarée ou héritée d’un parent.
- Si une image sert de fond (`background-image`), elle doit être associée à une couleur de fond par défaut.

## Couleur de fond créée par une image
**Images de fond** (CSS  `background` / `background-image`, ou HTML), utilisées pour créer
une couleur de fond pour du texte.

Elles doivent être **accompagnées d’une couleur de fond par défaut** (`background-color`) qui garantit
un contraste conforme.


<details>
    <summary>
        ### Exemples
    </summary>

    <Example imgImport={NCMarseille}>
        Sur la page d’accueil de [marseille.fr](https://www.marseille.fr/), le fond du bloc
        « Vous cherchez un équipement dans Marseille ? » est créé avec une image.

        Si elle n’est pas affichée, le texte blanc n’est plus suffisamment contrasté avec le fond.
    </Example>
</details>

## Aide à la détection
### Méthode 1 — inspection des CSS
- Rechercher dans les CSS si la balise `html` dispose d’une déclaration de couleur de police (`color`).
- Si oui, si une déclaration de couleur de fond `background`, `background-color` est présente.
- Sinon, descendre dans l’arborescence.

### Méthode 2 — Paramètre Couleurs Firefox
Visualiser rapidement des erreurs de déclaration en modifiant le paramètre Couleurs de Firefox.

- Dans les paramètres (about:preferences), section « Couleurs », sélectionner « Gérer les couleurs… ».
- Décocher l’option « Utiliser les couleurs système ».
- S’assurer que la liste de sélection « Outrepasser les couleurs spécifiées » est à « Jamais ».
- Valider et vérifier si les couleurs définies dans les paramètres Firefox s’appliquent.

__Conseil : choisir des couleurs distinctives et facilement repérables.__
