# Dans chaque page web, l’information reste-t-elle [compréhensible](https://accessibilite.numerique.gouv.fr/methode/glossaire/#comprehensible-ordre-de-lecture) lorsque les [feuilles de styles](https://accessibilite.numerique.gouv.fr/methode/glossaire/#feuille-de-style) sont désactivées ?

<CriteriaA/>
<IconedLink>[Lien RGAA](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#10.3)</IconedLink>
<BookmarkletTags names={["0 Désactiver CSS"]} />

## Que vérifie-t-on ?

L’ordre de succession des éléments dans le code source doit être logique.

**Cas typiques** : bandeau de cookies, dates, catégories et tags sur les vignettes d’actualités ou résultats de recherche.

Note : **les bandeaux d’acceptation des cookies doivent être systématiquement présents en premier dans le code HTML**,
car ils représentent une condition de consultation préalable. Visuellement, ils peuvent, en revanche, être présentés
en bas de page.

<details>
    <summary>
        ## Exemples
    </summary>

    <Example imgImport={NCLibe}>
        Sur [Libération](https://www.liberation.fr/), les catégories sont situées avant le titre de l’article.
        Les personnes aveugles qui naviguent par titre peuvent attribuer la mauvaise catégorie à l’article.
    </Example>

    <Example imgImport={CMediapart} comply>
        Sur [Mediapart](https://www.mediapart.fr/), la catégorie de l’article est située
        après le titre dans le code source et placée avant le titre visuellement.
    </Example>

    <Example imgImport={NCLEquipe}>
        Sur le site [lequipe.fr](https://www.lequipe.fr/Tennis/roland-garros/epreuve-simple-dames/page-tableau-tournoi),
        la présentation des résultats de tennis est compréhensible uniquement avec la mise en forme.
        Une personne aveugle ne peut les comprendre, car le lecteur d’écran lira simplement une succession de chiffres
        non structurée.
    </Example>

    <Example imgImport={COrijime} comply>
        Dans la page de présentation d’[Orejime](https://orejime.empreintedigitale.fr/), le gestionnaire de cookies
        est le premier élément du code source bien qu’il soit positionné visuellement en base de page.
    </Example>
</details>

## Aide à la détection
<BookmarkletTags names={["0 Désactiver CSS"]} />

- Repérer dans la page (CSS activées) des contenus, dont l’ordre de succession pourrait poser des problèmes,
par exemple une date avant un titre.
- Désactiver les feuilles de styles et vérifier que la succession des éléments est cohérente et logique
(la date suit le titre par exemple).
