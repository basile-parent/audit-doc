# Pour chaque page web, les contenus peuvent-ils être présentés sans perte d’information ou de fonctionnalité et sans avoir recours soit à un défilement vertical pour une fenêtre ayant une hauteur de 256px, soit à un défilement horizontal pour une fenêtre ayant une largeur de 320px (hors cas particuliers) ?

<CriteriaAA/>
<IconedLink>[Lien RGAA](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#10.11)</IconedLink>

## Que vérifie-t-on ?

Les contenus doivent pouvoir être présentés à l’utilisateur **sans utilisation des deux ascenseurs et sans perte
d’information** :

- dans une fenêtre de largeur réduite à **320px** pour les contenus dont le sens de consultation est vertical ;
- dans une fenêtre de hauteur réduite à **256px** pour les contenus dont le sens de consultation est horizontal.

**Cas particuliers :**

Tableaux de données, images, graphiques, vidéos, cartes, jeux, présentation (diaporama).

**Important :** ce critère ne teste pas l’utilisation mobile, mais le zoom à 400 % dans une fenêtre de 1280px.
Voir [Understanding SC 1.4.10: Reflow](https://www.w3.org/WAI/WCAG21/Understanding/reflow.html).

## Aide à la détection : linéarisation des contenus
Vue adaptative de Firefox :
- Windows : `Ctrl + Maj + M`
- MacOS : `option + Cmd + M`

## Cas particuliers

L'objectif de ce critère est de garantir un défilement dans une unique direction pour une lecture
facilitée selon le sens de l'écriture.

Font exception à ce critère, les contenus dont l'agencement requiert deux dimensions pour être compris
ou utilisés comme :

*   Les images, les graphiques ou les vidéos ;
*   Les jeux (jeux de plateforme, par exemple) ;
*   Les présentations (type diaporama, par exemple) ;
*   Les tableaux de données ;
*   Les interfaces où il est nécessaire d'avoir un ascenseur horizontal lors de la manipulation de l'interface.

Note : la majorité des navigateurs sur les systèmes d'exploitation sur mobile (Android, iOS) ne gère pas
correctement la redistribution en cas de zoom. Dans ce contexte, le critère sera considéré comme non applicable
sur ces environnements.

## Note technique

Lorsqu'il est ici question de pixel, il s'agit du pixel CSS tel que défini par le W3C https://www.w3.org/TR/css3-values/
