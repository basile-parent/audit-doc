# Dans chaque page web, le [contenu visible](https://accessibilite.numerique.gouv.fr/methode/glossaire/#contenu-visible) porteur d’information reste-t-il présent lorsque les [feuilles de styles](https://accessibilite.numerique.gouv.fr/methode/glossaire/#feuille-de-style) sont désactivées ?

<CriteriaA/>
<IconedLink>[Lien RGAA](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#10.2)</IconedLink>
<BookmarkletTags names={["10.2 Contenu CSS"]} />

## Que cherche-t-on ?

Les éléments porteurs d’information insérés avec CSS doivent avoir un équivalent textuel
ou être insérés directement en HTML.

Exemples :
- les images de fond CSS (`background-image`) porteuses d’information
- le contenu inséré par CSS `content:’[texte]’`.

## Aide à la détection
### Méthode 1
Comparer la page CSS activées et CSS désactivées et repérer les éléments porteurs d’information qui disparaissent.

### Méthode 2
<BookmarkletTags names={["10.2 Contenu CSS"]} />

- Sur la page (CSS activées), activer le bookmarklet.
- Repérer les éléments porteurs d’information parmi les contenus entourés.
- Vérifier si ces contenus insérés avec CSS ont un équivalent textuel (ex. texte inséré hors écran).
