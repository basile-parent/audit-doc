# Chaque page web a-t-elle un [titre de page](https://accessibilite.numerique.gouv.fr/methode/glossaire/#titre-de-page) ?

<CriteriaA/>
<IconedLink>[Lien RGAA](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#8.5)</IconedLink>

## Que vérifie-t-on ?

La page web a-t-elle un titre (balise `<title>`) ?

Accessible depuis l’onglet et l’historique de navigation du navigateur, premier élément restitué
par le lecteur d’écran au chargement de la page.
