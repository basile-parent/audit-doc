# Dans chaque page web, le code de langue de chaque [changement de langue](https://accessibilite.numerique.gouv.fr/methode/glossaire/#changement-de-langue) est-il valide et pertinent ?

<CriteriaAA/>
<IconedLink>[Lien RGAA](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#8.8)</IconedLink>

## Que vérifie-t-on ?

La pertinende de l'attribut `lang` des éléments de la page :
[Code de langue pertinent et valide (ISO 639)](https://fr.wikipedia.org/wiki/ISO_639).

## Aide à la détection
<BookmarkletTags names={["08 Langue et direction"]} />

- Exécuter le bookmarklet.
- Vérifier pour tous les mots encadrés que la valeur de l’attribut `lang` est **pertinente**.

Les **extensions de correction orthographique** peuvent aider à détecter des termes en langue étrangère
(par exemple : [Grammalecte](https://addons.mozilla.org/fr/firefox/addon/grammalecte-fr/) sur Firefox).
