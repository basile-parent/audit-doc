# Dans chaque page web, les balises ne doivent pas être utilisées [uniquement à des fins de présentation](https://accessibilite.numerique.gouv.fr/methode/glossaire/#uniquement-a-des-fins-de-presentation). Cette règle est-elle respectée ?

<CriteriaA/>
<IconedLink>[Lien RGAA](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#8.9)</IconedLink>
<BookmarkletTags names={["08.9 Sémantique"]} />

## Que vérifie-t-on ?

Utiliser les éléments HTML pour leur rôle prévu.

Exemples de détournement :

- `<div>` pour créer des paragraphes,
- `<hx>` détournés pour le référencement,
- `<p>` vides.

:::note

Note : l’utilisation de la propriété `role="presentation"` peut servir à supprimer la sémantique d’un élément.
Son utilisation est néanmoins **fortement déconseillée** et **non conforme** dans le cas où la sémantique est
essentielle (par exemple sur un titre `hx`).

:::

<details>
    <summary>
        ## Exemples
    </summary>

    <Example imgImport={NCCorreze}>
        Sur le site [Tourisme Corrèze](https://www.tourismecorreze.com/fr/recherche?qs=vert&page=5),
        « Nos conseils / Nos coups de cœur » est structuré avec un titre (`h4`) alors qu’il ne constitue pas un titre.
        Ce texte devrait être un simple paragraphe.
    </Example>
</details>

## Aide à la détection
<BookmarkletTags names={["08.9 Sémantique"]} />

- Vérifier que tous les éléments textuels sont entourés.
- Vérifier que la sémantique associée est pertinente.

<img src={BMDemo} alt="Illustration du bookmarklet" />

:::note

Afin de ne pas surcharger l’affichage, le bookmarklet n’indique pas les éléments `<li>`.

:::
