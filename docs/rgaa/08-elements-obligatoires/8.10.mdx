# Dans chaque page web, les changements du [sens de lecture](https://accessibilite.numerique.gouv.fr/methode/glossaire/#sens-de-lecture) sont-ils signalés ?

<CriteriaA/>
<IconedLink>[Lien RGAA](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#8.10)</IconedLink>

## Que vérifie-t-on ?

- Attribut `dir` sur l’élément lui-même ou un parent doit avoir comme valeur `ltr` (gauche à droite) ou `rtl` (droite à gauche)
- La valeur `ltr` est implicite et peut être omise sur l’élément `html`.
- Si l’attribut `dir` est présent, sa valeur doit être pertinente.
