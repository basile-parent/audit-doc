# Pour chaque page web ayant un [titre de page](https://accessibilite.numerique.gouv.fr/methode/glossaire/#titre-de-page), ce titre est-il pertinent ?

<CriteriaA/>
<IconedLink>[Lien RGAA](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#8.6)</IconedLink>

- Dans la mesure du possible, les titres sont uniques dans un site web.
- Mention des détails de la collection : tag, catégorie, etc. Ex: `Articles pour la catégorie « Emploi »`
- Mention de la pagination : `Recherche pour "tourisme" — Page 3 sur 4`

<details>
    <summary>
        ## Exemples
    </summary>

    <Example imgImport={NCCorreze}>
        Sur le site [Tourisme Corrèze](https://www.tourismecorreze.com/fr/recherche?qs=vert&page=5),
        les titres des pages de résultats de recherche ne reprennent ni le terme recherché ni la pagination.
