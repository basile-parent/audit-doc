# Dans chaque page web, la [structure du document](https://accessibilite.numerique.gouv.fr/methode/glossaire/#structure-du-document) est-elle cohérente (hors cas particuliers) ?

## Les éléments

### `<nav>`

Plusieurs éléments `<nav>` peuvent être présents sur la page. Chaque élément doit identifier un élément de navigation
**dans le site**, parmi :
- éléments de navigation principaux : navigation principale, secondaire, navigation contextuelle
- navigation dans les collections de pages, pagination
- les liens d’accès rapide
- le fil d’Ariane
- table des matières

Une balise `<nav>` utilisée sur un autre type de contenu est une non-conformité.

### `<header>`

Plusieurs balises `<header>` peuvent être utilisées dans la page. On vérifie que l’en-tête principal
du site au moins soit dans une balise `<header>`. On n’évalue pas les autres.

- Obligatoire pour l’entête du document
- Peut contenir des titres, de la navigation

### `<footer>`

Plusieurs balises `<footer>` peuvent être utilisées dans la page. On vérifie que le pied de page principal
du site au moins soit dans une balise `<footer>`. On n’évalue pas les autres.

- Obligatoire pour le pied de page du document

### `<main>`

Regroupement du contenu principal de la page _(les éléments répétés - navigation, publicité -
ne devraient pas être structurés avec)_

- Obligatoire
- et **unique** dans la page

## Aide à la détection
<BookmarkletTags names={["09.2 12.6 Sémantique"]} />

Vérifier que :
- l’entête principal est intégré dans une balise `<header>`.
- le menu principal est intégré dans une balise `<nav>`.
- les autres systèmes de navigation (fil d’ariane par exemple), s’ils sont présents, sont intégrés dans une balise `<nav>`.
- les balises `<nav>` ne sont pas utilisées pour structurer des contenus qui ne sont pas des systèmes de navigation
(par exemple, une liste de liens externes au site).
- le contenu principal est intégré dans une balise `<main>` et que la balise est unique dans la page.
- le pied de page est intégré dans une balise `<footer>`

## Cas particuliers

Lorsque le doctype déclaré dans la page n’est pas le doctype HTML5, ce critère est non applicable.

## Notes techniques

La balise `<main>` peut être utilisée plusieurs fois dans le même document HTML. Néanmoins, il ne peut y avoir
en permanence qu’une seule balise visible et lisible par les technologies d’assistances, les autres devant disposer
d’un attribut `hidden` ou d’un style permettant de les masquer aux technologies d’assistances.

À noter cependant que l’utilisation d’un style seul restera insuffisante pour assurer l’unicité d’une balise `<main>`
visible en cas de désactivation des feuilles de styles.
