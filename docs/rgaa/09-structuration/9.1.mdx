# Dans chaque page web, l’information est-elle structurée par l’utilisation appropriée de [titres](https://accessibilite.numerique.gouv.fr/methode/glossaire/#titre) ?

<CriteriaA/>
<IconedLink>[Lien RGAA](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#9.1)</IconedLink>

## Que vérifie-t-on ?

On vérifie 3 éléments pour les titres :
- Hiérarchie cohérente (imbrication des niveaux de titres, l’imbrication respecte la logique du contenu)
- Titres pertinents
- Tous les titres nécessaires.

**Les cas suivants ne constituent pas une non-conformité** : l’absence de titres, l’absence de h1,
une hiérarchie qui ne débute pas par un h1, plusieurs h1, les sauts hiérarchiques (passer de h1 à h3 par exemple).

## Notes techniques

WAI-ARIA permet de définir des titres via le rôle `heading` et l’attribut `aria-level` (indication du niveau de titre).
Bien qu’il soit préférable d’utiliser l’élément de titre natif en HTML `<hx>`, l’utilisation du rôle WAI-ARIA `heading`
est compatible avec l’accessibilité.
