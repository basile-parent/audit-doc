# 3.2 Dans chaque page web, le [contraste](https://accessibilite.numerique.gouv.fr/methode/glossaire/#contraste) entre la couleur du texte et la couleur de son arrière-plan est-il suffisamment élevé (hors cas particuliers) ?
<CriteriaAA />
<IconedLink>[Lien RGAA](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#3.2)</IconedLink>

## Comment le tester ?

<ExtensionsTags names={["WCAG Contrast color checker", "aXe DevTools"]} />

- Lancer les 2 extensions eet vérifier les contrastes détectés automatiquement
- Sur toute la page, vérifier manuellement les contrastes étranges dans :
    - les textes
    - les textes en images
    - les sous-titres incrustés

Si le site dispose d'un thème contrasté, il faut tester via ce thème.

:::note

Regarder la **taille calculée** (dans l'onglet "Calculé" des DevTools) ; pas forcément la déclaration CSS.

**Attention** : les textes de décoration sont exemptés (voir [Cas particuliers](#cas-particuliers))

:::

## Résumé des tests

Rappel des niveaux de contraste :
- taille normale (_< 24px ou 18,5px **en gras**_) : au moins **4,5:1**
- taille agrandie (_>= 24px ou 18,5px **en gras**_) : au moins **3:1**

## Cas particuliers

Dans ces situations, les critères sont non applicables pour ces éléments :

*   Le texte fait partie d’un logo ou d’un nom de marque d’un organisme ou d’une société
*   Le texte ou l’image de texte est purement décoratif
*   Le texte fait partie d’une image véhiculant une information mais le texte lui-même n’apporte aucune information essentielle
*   Le texte ou l’image de texte fait partie d’un élément d’interface sur lequel aucune action n’est possible (par exemple un bouton avec l’attribut `disabled`).
