# 1.1 Chaque image porteuse d’information a-t-elle une alternative textuelle ?

<IconedLink>[Lien RGAA](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#1.1)</IconedLink>

## Comment le tester ?

<BookmarkletTags names={["0 Désactiver CSS", "01 Images", "List images"]} />

- Désactiver le CSS (optionnel mais plus pratique pour les contenus cachés)
- Lancer le BM `01 Images`
- Repérer les images **porteuses d'information** parmi les éléments entourés.
- Vérifier la présence d'une alternative textuelle

<hr/>

- Lancer le BM `List images`

:::warning

On ne juge pas ici de la **pertinence** de l'alternative. Voir le [critère 1.3](/docs/rgaa/images/1.3)

:::

## Tests et références

### 1.1.1
Chaque image (balise `<img>` ou balise possédant l’attribut WAI-ARIA `role="img"`) **porteuse d’information** a-t-elle une alternative textuelle ?

<Disclosure title="Méthodologie">
1. Retrouver dans le document les images structurées au moyen d’un élément `<img>` ou d’un élément possédant l’attribut WAI-ARIA `role="img"` ;
1. Pour chaque image, déterminer si l’image est porteuse d’information ;
1. Dans le cas où il s’agit d’un élément `<img>`, vérifier que l’image est pourvue au moins d’une alternative textuelle parmi les suivantes :
   - Passage de texte associé via l’attribut WAI-ARIA `aria-labelledby` ;
   - Contenu de l’attribut WAI-ARIA `aria-label` ;
   - Contenu de l’attribut `alt` ;
   - Contenu de l’attribut `title`.
1. Dans le cas où il s’agit d’un élément possédant l’attribut WAI-ARIA `role="img"`, vérifier que l’image est pourvue au moins d’une alternative textuelle parmi les suivantes :
   - Passage de texte associé via l’attribut WAI-ARIA `aria-labelledby` ;
   - Contenu de l’attribut WAI-ARIA `aria-label`.
1. Si au moins une alternative textuelle est trouvée, **le test est validé**.
</Disclosure>
