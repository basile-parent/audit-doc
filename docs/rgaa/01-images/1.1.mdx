# 1.1 Chaque [image porteuse d’information](https://accessibilite.numerique.gouv.fr/methode/glossaire/#image-porteuse-d-information) a-t-elle une [alternative textuelle](https://accessibilite.numerique.gouv.fr/methode/glossaire/#alternative-textuelle-image) ?
<CriteriaA />
<IconedLink>[Lien RGAA](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#1.1)</IconedLink>

## Comment le tester ?

<BookmarkletTags names={["0 Désactiver CSS", "01 Images", "List images"]} />

- Désactiver le CSS (optionnel mais plus pratique pour les contenus cachés).
- Lancer le BM `01 Images`.
- Repérer les images **porteuses d'information** parmi les éléments entourés.
- Vérifier la présence d'une alternative textuelle.

<hr/>

- Lancer le BM `List images`.

:::note

Les différents moyens de positionner une alternative textuelle aux images porteuses d'information sont:

```html
<img src="" alt="[alternative]" />

<img src="img.png" aria-labelledby="id_alt"/>
<span id="id_alt">un texte alternatif</span>

<img src="img.png" aria-label="[alternative]"/>

<img src="img.png" title="[alternative]"/>

<!-- Rappel: le rôle="img" est obligatoire -->
<svg role="img" aria-label="espace utilisateur">
  [...]
</svg>

<svg role="img" aria-labelledby="id_title">
  <title id="id_title">espace utilisateur</title>
  [...]
</svg>
```

[Calcul du nom accessible](https://www.w3.org/TR/html-aam-1.0/):
1. `aria-labelledby="@id-alternative"`
1. `aria-label="[alternative]"`
1. attribut `alt="[alternative]"`
1. attribut `title="[alternative]"`
:::

## Résumé des tests

:::warning

On ne juge pas ici de la **pertinence** de l'alternative. Voir le [critère 1.3](./1.3)

:::

- Pour chaque `<img>`, vérifier l'alternative : `aria-labelledby`, `aria-label`, `alt`, `title` <IconedLink>[test 1.1.1](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#1.1.1)</IconedLink>
- Pour chaque `role="img"`, vérifier l'alternative : `aria-labelledby`, `aria-label` <IconedLink>[test 1.1.1](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#1.1.1)</IconedLink>
- Pour chaque chaque [zone](https://accessibilite.numerique.gouv.fr/methode/glossaire/#zone-d-une-image-reactive)
    d’une [image réactive](https://accessibilite.numerique.gouv.fr/methode/glossaire/#image-reactive)
    (balise `<area>`), vérifier l'alternative : `aria-label`, `alt` <IconedLink>[test 1.1.2](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#1.1.2)</IconedLink>
- Pour chaque bouton de type `image` (balise `<input>` avec l’attribut `type="image"`), vérifier l'alternative : `aria-label`, `alt`, `title` <IconedLink>[test 1.1.3](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#1.1.3)</IconedLink>
- Pour chaque [zone cliquable](https://accessibilite.numerique.gouv.fr/methode/glossaire/#zone-cliquable)
    d’une image réactive côté serveur (`<img/>` pourvus de l’attribut `ismap`), vérifier qu'elle a un mécanisme accessible :
    présence d’un lien ou d’un ensemble de liens (ou bien d’un autre type de composant d’interface qui jouerait un rôle
    similaire comme une liste de sélection, par exemple) permettant d’accéder aux mêmes ressources que lorsque l’image fait l’objet d’un clic.
    <IconedLink>[test 1.1.4](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#1.1.4)</IconedLink>
- Pour chaque image vectorielle (balise `<svg>`), vérifier : la présence d'un `role="img"` **ET** l'alternative textuelle :
    balise `<title>`, `aria-labelledby`, `aria-label` <IconedLink>[test 1.1.5](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#1.1.5)</IconedLink>
- Vérifier directement sur le référentiel :
    - [Images objets](https://accessibilite.numerique.gouv.fr/methode/glossaire/#image-objet) (balise `<object>` avec l’attribut `type="image/…"`) <IconedLink>[test 1.1.6](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#1.1.6)</IconedLink>
    - Images embarquées (balise `<embed>` avec l’attribut `type="image/…"`) <IconedLink>[test 1.1.7](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#1.1.7)</IconedLink>
    - Images bitmap (balise `<canvas>`) <IconedLink>[test 1.1.8](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#1.1.8)</IconedLink>
