## Comment le tester ?

Jusqu'à maintenant, les images CAPTCHA ont toujours été dérogées car script externe (évalué dans le [critère 7.1](/docs/rgaa/scripts/7.1))

:::warning

**Attention :** Même si dérogés, les CAPTCHA doivent respecter le (principe de non-interférence)[https://access42.net/principe-non-interference-accessibilite-numerique/].

Voir l'article (Inaccesibility of CAPTCHA (W3C))[https://www.w3.org/TR/turingtest/]

:::
