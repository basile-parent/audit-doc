# 1.3 Pour chaque image porteuse d’information ayant une alternative textuelle, cette alternative est-elle pertinente (hors cas particuliers) ?

## Comment le tester ?

<BookmarkletTags names={["0 Désactiver CSS", "01 Images", "Complément/List images"]} />

- Désactiver le CSS (optionnel mais plus pratique pour les contenus cachés)
- Lancer le BM `01 Images`
- Repérer les images porteuses d'information parmi les éléments entourés.
- Vérifier la **pertinence** des alternatives textuelles

<hr/>

- Lancer le BM `Complément/List images`
