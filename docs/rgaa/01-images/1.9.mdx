# 1.9 Chaque [légende d’image](https://accessibilite.numerique.gouv.fr/methode/glossaire/#legende-d-image) est-elle, si nécessaire, correctement reliée à l’image correspondante ?

## Comment le tester ?

<BookmarkletTags names={["0 Désactiver CSS", "01 Images"]} />

- Désactiver le CSS (optionnel mais plus pratique pour les contenus cachés).
- Lancer le BM `01 Images`.
- Repérer les images porteuses d'information **associées visuellement à une légende**.
- Vérifier que l'image et sa légende sont biwen inclus dans une balise `<figure>`

## Rappel de la sctructure type

```html
<figure role="group" aria-label="[contenu du figcaption]">
    <img src="…" alt="label-image" />
    <figcaption>
        [label-image] Légende de l’image
    </figcaption>
</figure>
```

## Résumé des tests

Lexique :
- [Légende](https://accessibilite.numerique.gouv.fr/methode/glossaire/#legende-d-image)

Pour chaque :
- image pourvue d’une légende (balise `<img>`, `<input>` avec l’attribut `type="image"` ou possédant un attribut WAI-ARIA `role="img"`
associée à une légende adjacente) <IconedLink>[test 1.9.1](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#1.9.1)</IconedLink>
- [image objet](https://accessibilite.numerique.gouv.fr/methode/glossaire/#image-objet) pourvue d’une légende
(balise `<object>` avec l’attribut `type="image/…"` associée à une légende adjacente) <IconedLink>[test 1.9.2](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#1.9.2)</IconedLink>
- Chaque image embarquée pourvue d’une légende (balise `<embed>` associée à une légende adjacente) <IconedLink>[test 1.9.3](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#1.9.3)</IconedLink>
- Chaque image vectorielle pourvue d’une légende (balise `<svg>` associée à une légende adjacente) <IconedLink>[test 1.9.4](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#1.9.4)</IconedLink>
- Chaque image bitmap pourvue d’une légende (balise `<canvas>` associée à une légende adjacente) <IconedLink>[test 1.9.5](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#1.9.5)</IconedLink>

vérifier :
- L’image et sa légende adjacente sont contenues dans une balise `<figure>`
- La balise `<figure>` possède un attribut WAI-ARIA `role="figure"` ou `role="group"`
- La balise `<figure>` possède un attribut WAI-ARIA `aria-label` dont le contenu est identique au contenu de la légende
- La légende est contenue dans une balise `<figcaption>`

## Note technique

L’implémentation d’un attribut WAI-ARIA `role="group"` ou `role="figure"` sur l’élément parent `<figure>` est destiné
à pallier le manque de support actuel des éléments `<figure>` par les technologies d’assistance. L’utilisation
d’un élément `<figcaption>` pour associer une [légende](https://accessibilite.numerique.gouv.fr/methode/glossaire/#legende-d-image)
à une image impose au minimum l’utilisation d’un attribut WAI-ARIA `aria-label` sur l’élément parent `<figure>` dont le
contenu sera identique au contenu de l’élément `<figcaption>`. Pour s’assurer d’un support optimal, il peut également
être fait une association explicite entre le contenu de l’[alternative textuelle](https://accessibilite.numerique.gouv.fr/methode/glossaire/#alternative-textuelle-image)
de l’image et le contenu de l’élément `<figcaption>`, par exemple

```html
<img src="image.png" alt="Photo : soleil couchant" />
<figcaption>Photo : crédit xxx</figcaption>
```

Les attributs WAI-ARIA `aria-labelledby` et `aria-describedby` ne peuvent pas être utilisés actuellement par manque
de support par les technologies d’assistance.

Note : les images légendées doivent par ailleurs respecter le critère 1.1 et le critère 1.3 relatifs aux images
porteuses d’information.
