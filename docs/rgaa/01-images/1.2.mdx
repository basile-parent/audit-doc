# 1.2 Chaque [image de décoration](https://accessibilite.numerique.gouv.fr/methode/glossaire/#image-de-decoration) est-elle correctement ignorée par les technologies d’assistance ?

<IconedLink>[Lien RGAA](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#1.2)</IconedLink>

## Comment le tester ?

<BookmarkletTags names={["0 Désactiver CSS", "01 Images", "List images"]} />

- Désactiver le CSS (optionnel mais plus pratique pour les contenus cachés).
- Lancer le BM `01 Images`.
- Repérer les images **de décoration** parmi les éléments entourés.
- Vérifier la présence d’une méthode adéquate pour ignorer l’image.

<hr/>

- Lancer le BM `List images`

:::note

Pour les images de décoration légendées, voir la partie [Note technique](#note-technique).

Pour les `<svg>` imbriqués dans des `<use>`, voir la partie [Note technique](#note-technique).

Les différents moyens d'identifier une image de décoration sont:

```html
<img src="img.png" alt=""/>
<img src="img.png" aria-hidden="true"/>
<img src="img.png" role="presentation"/>
```

:::

## Résumé des tests

- Pour chaque image (balise `<img>`) [de décoration](https://accessibilite.numerique.gouv.fr/methode/glossaire/#image-de-decoration), sans [légende](https://accessibilite.numerique.gouv.fr/methode/glossaire/#legende-d-image), vérifier : <IconedLink>[test 1.2.1](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#1.2.1)</IconedLink>
    - `alt` vide (`alt=""`) et pas d'autre alternative textuelle
    - ou `aria-hidden="true"` / `role="presentation"`
- Pour chaque [zone non cliquable](https://accessibilite.numerique.gouv.fr/methode/glossaire/#zone-non-cliquable) (balise `<area>` sans attribut `href`), vérifier : <IconedLink>[test 1.2.2](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#1.2.2)</IconedLink>
    - `alt` vide (`alt=""`) et pas d'autre alternative textuelle **sur la balise `<area>`**
    - ou `aria-hidden="true"` / `role="presentation"` **sur la balise `<area>`**
- Pour chaque [image objet](https://accessibilite.numerique.gouv.fr/methode/glossaire/#image-objet) (balise `<object>` avec l’attribut `type="image/…"`), vérifier : <IconedLink>[test 1.2.3](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#1.2.3)</IconedLink>
    - `aria-hidden="true"`
    - **ET** pas d'alternative textuelle : `aria-labelledby`, `aria-label` ou `title`
    - **ET** aucun texte faisant office d’alternative textuelle entre `<object>` et `</object>`
- Pour chaque image vectorielle (balise `<svg>`), vérifier : <IconedLink>[test 1.2.4](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#1.2.4)</IconedLink>
    - `aria-hidden="true"`
    - **ET** la balise `<svg>` et ses enfants sont dépourvus d’[alternative textuelle](https://accessibilite.numerique.gouv.fr/methode/glossaire/#alternative-textuelle-image) et d’attribut `title`
    - **ET** les balises `<title>` et `<desc>` sont absentes ou vides
- Pour chaque image bitmap (balise `<canvas>`) : <IconedLink>[test 1.2.5](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#1.2.5)</IconedLink>
    - `aria-hidden="true"`
    - **ET** la balise `<canvas>` et ses enfants sont dépourvus d’[alternative textuelle](https://accessibilite.numerique.gouv.fr/methode/glossaire/#alternative-textuelle-image)
    - **ET** il n’y a aucun texte faisant office d’[alternative textuelle](https://accessibilite.numerique.gouv.fr/methode/glossaire/#alternative-textuelle-image) entre `<canvas>` et `</canvas>`
- Chaque image embarquée (balise `<embed>` avec l’attribut `type="image/…"`) : <IconedLink>[test 1.2.6](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#1.2.6)</IconedLink>
    - `aria-hidden="true"`
    - **ET** la balise `<embed>` et ses enfants sont dépourvus d’[alternative textuelle](https://accessibilite.numerique.gouv.fr/methode/glossaire/#alternative-textuelle-image)

## Note technique

Lorsqu'une image est associée à une [légende](https://accessibilite.numerique.gouv.fr/methode/glossaire/#legende-d-image), la note technique WCAG recommande de prévoir systématiquement une [alternative textuelle](https://accessibilite.numerique.gouv.fr/methode/glossaire/#alternative-textuelle-image) (cf. critère 1.9). Dans ce cas le critère 1.2 est non applicable.

Dans le cas d'une image vectorielle (balise `<svg>`) de décoration qui serait affichée au travers d'un élément `<use href="…">` enfant de l'élément `<svg>`, le test 1.2.4 s'appliquera également à l'élément `<svg>` associée par le biais de l'élément `<use>`.

Un attribut WAI-ARIA `role="presentation"` peut être utilisé sur les images de décoration et les zones non cliquables de décoration. Le rôle `"none"` introduit en ARIA 1.1 et synonyme du rôle `"presentation"` peut être aussi utilisé. Il reste préférable cependant d'utiliser le rôle `"presentation"` en attendant un support satisfaisant du rôle `"none"`.
