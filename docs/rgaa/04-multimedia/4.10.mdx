# Chaque son déclenché automatiquement est-il [contrôlable](https://accessibilite.numerique.gouv.fr/methode/glossaire/#controle-son-declenche-automatiquement) par l’utilisateur ?
<CriteriaA/>
<IconedLink>[Lien RGAA](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#4.10)</IconedLink>

Les sons déclenchés automatiquement doivent être contrôlables par l’utilisateur,
**sauf si la durée est inférieure à 3 secondes**.

L’utilisateur peut :

- Stopper le média
- ou contrôler le volume sonore indépendamment du volume système.

Cette problématique impacte fortement les **utilisateurs aveugles** qui naviguent avec un lecteur d’écran
avec sortie vocalisée et les utilisateurs avec un **trouble de l’attention**.

Le contrôle permettant de couper le son devrait être de préférence le premier élément de la page.
