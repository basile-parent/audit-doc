# Chaque [média non temporel](https://accessibilite.numerique.gouv.fr/methode/glossaire/#media-non-temporel) a-t-il, si nécessaire, une alternative (hors cas particuliers) ?
<CriteriaA/>
<IconedLink>[Lien RGAA](https://accessibilite.numerique.gouv.fr/methode/criteres-et-tests/#4.8)</IconedLink>

<BookmarkletTags names={["4.8 - Non temporel"]} />

Animations intégrées dans `<canvas>` ou `<svg>`.

Mise à disposition systématique d’une alternative présentant les mêmes contenus et les mêmes fonctionnalités (si nécessaire).

## Cas particuliers

- Média purement décoratif
- Média diffusé dans un [environnement maîtrisé](https://accessibilite.numerique.gouv.fr/methode/glossaire/#environnement-maitrise)
- Média inséré via JavaScript en vérifiant la présence et la version du plug-in, en remplacement d’un [contenu alternatif](https://accessibilite.numerique.gouv.fr/methode/glossaire/#contenu-alternatif) déjà présent.
