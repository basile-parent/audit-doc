## Comment tester ?

- Vérifier que les vidéos ont des sous-titres incrustés ou ajoutés via la balise `<track>`

:::info

Dans le cas d’une vidéo embarquée avec la balise HTML5 `<video>`, la balise `<track>` qui embarque
les sous-titres doit être correctement définie comme étant la piste des sous-titres pour sourds
et malentendants (_closed captions, CC_), et non pas comme sous-titres de traduction (_subtitles_).

```
<video>
    <track kind="captions" label="Français" src="stitre.srt" />
</video>
```

`kind="subtitles"` dédié aux sous-titres de traduction.

:::
